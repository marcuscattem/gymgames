# Glossário de ginástica artística

| Termo no Código | Tradução nas tabelas |
|---|---|
| fwd / bwd / swd | Para frente / para trás / para o lado |
| hstd / hdst | Parada de mãos |
| tucked / piked / stretched | Grupado / carpado / estendido |
| straddled | Afastado |
| mount (MT) / dismount (DMT) | Entrada / saída |
| round-off | Rondada |
| handspring | Reversão |
| flic-flac | Flic-flac |
| kip | Kipe |
| turn / salto | Giro / mortal |
| LA | Eixo longitudinal |
| HB / LB nas assimétricas | Barra alta / barra baixa |

A abreviação `t.` pode significar *tucked* ou *turn*, conforme o contexto.
