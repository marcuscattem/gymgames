# GAM (MAG) — Tabela de elementos — Barras Paralelas (Parallel Bars)

> Fonte: FIG — Men's Artistic Gymnastics Code of Points 2025-2028 (PDF na raiz desta pasta). A coluna **Elemento (português)** traz o nome completo traduzido, por extenso (sem as abreviações do Código); a coluna **Original (inglês)** mantém o texto do documento oficial. As traduções ficam em `regras/traducoes/` e podem ser corrigidas ali. Glossário: [glossario.md](glossario.md).
> Extraído automaticamente do PDF; em caso de dúvida, o PDF oficial prevalece. Abreviações: fwd = para frente, bwd = para trás, swd = para o lado, hstd/hdst = parada de mãos, t. = tucked (grupado) ou turn (giro) conforme o contexto, p. = piked (carpado), str. = stretched/straight (estendido), strad. = afastado, DMT = saída, MT = entrada, LA = eixo longitudinal, HB/LB = barra alta/baixa.


**Código** `EG.N` (ex.: `III.18`): grupo de elementos + número de identificação da caixa. Elementos na mesma caixa têm o mesmo número de identificação (repetição não recebe valor).

Valores: A 0,1 · B 0,2 · C 0,3 · D 0,4 · E 0,5 · F 0,6 · G 0,7 · H 0,8 · I 0,9 · J 1,0
